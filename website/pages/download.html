Download

Install with one command.

The installers pick the right build for your machine and check its SHA-256 checksum. Pick the edition first: the enterprise build is the same program with the enterprise features, which a license or trial unlocks.

Linux and macOS

$ curl -fsSL https://github.com/PlugOvr-ai/meshvpn/releases/latest/download/install.sh | sudo sh

Install and join in one step: ... | sudo sh -s -- join mesh1-.... Without sudo: ... | sh -s -- --user join mesh1-...

Windows 10/11

administrator PowerShell
irm https://github.com/PlugOvr-ai/meshvpn/releases/latest/download/install.ps1 | iex

Installs to C:\Program Files\meshvpn with the Wintun driver and starts at boot.

Packages

.deb and .rpm for x86_64, ARM64 and ARMv7, plain archives for every platform, on the releases page.

From source

$ cargo install --git https://github.com/PlugOvr-ai/meshvpn

Nodes: Linux and macOS

$ curl -fsSL https://github.com/PlugOvr-ai/meshvpn-enterprise-releases/releases/latest/download/install.sh | sudo sh

Then start a trial on an admin node: sudo meshvpn license trial --email you@example.com --accept-terms

Nodes: Windows 10/11

administrator PowerShell
$env:MESHVPN_EDITION = "enterprise"; irm https://github.com/PlugOvr-ai/meshvpn/releases/latest/download/install.ps1 | iex

Windows machines work as admin and user machines; bookable devices run Linux.

The portal (Linux with systemd)

$ curl -fsSL https://github.com/PlugOvr-ai/meshvpn-enterprise-releases/releases/latest/download/install-portal.sh \
    | sudo sh -s -- --public-host portal.example.com --admin ops

See the portal tutorial for HTTPS, ports and the first login. All files: enterprise releases.

What a release contains

FileWhat it is
install.sh, install.ps1Installers for Linux/macOS and Windows
meshvpn-<target>.tar.gz / .zipThe program: x86_64, aarch64, armv7 and arm Linux (static, musl), aarch64/x86_64 macOS, x86_64 Windows with wintun.dll
.deb, .rpmPackages (open source)
meshvpn-desktop-<arch>.tar.gzThe browser-desktop bundle, for machines without internet (open source)
install-portal.sh, meshvpn-portal-<target>.tar.gzThe portal (enterprise)
SHA256SUMS, *.sha256Checksums, verified by the installers and meshvpn update
*.cdx.jsonSoftware bill of materials (CycloneDX)

Update a node with sudo meshvpn update. Nodes show new releases in meshvpn status but never install them by themselves. Pin a version with MESHVPN_VERSION=v0.16.2.
